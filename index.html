Autenticar para salvar no GitHub

Qualquer pessoa pode ver o roadmap; para gravar é preciso um token do GitHub com permissão de escrita neste repositório. O token fica só na memória desta aba.

Como criar o token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → daniloceano/tc-renovaveis-roadmap.
  3. Permissions → Repository → Contents: Read and write. Nada mais.
  4. Defina uma validade (ex.: 90 dias), gere e cole acima.
