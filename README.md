# TC-Renováveis Roadmap

Roadmap interativo para acompanhamento das frentes de trabalho do projeto TC-Renováveis.

## Objetivo

Organizar visualmente tarefas planejadas, em andamento e concluídas, com páginas de detalhe por frente de trabalho e links relevantes para resultados e análises.

## Status

Projeto em fase inicial. Neste momento, o repositório contém apenas o esqueleto documental para posterior implementação do site em Next.js + Vercel.

## Planejado

- Estrutura inicial do app
- Roadmap visual interativo
- Páginas de detalhe por tarefa
- Fonte de dados simples para manutenção
- Preparação para deploy em Vercel
